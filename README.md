# Machine-Learning-Model-Evaluation-
The UCI Bank Marketing dataset (45,211 clients, 16 input features). Call duration was deliberately because it is only known after a call has been made. Only 11.7% of clients subscribed, so work uses a stratified train/test split, class-weighted models and imbalance-aware metrics (precision, recall, F1-score and ROC-AUC) instead of relying accuracy.
